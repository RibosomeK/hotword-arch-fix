# Xposed API 82

`api-82.jar` is the legacy Xposed API (version 82) used to compile this module.
It is not part of this project; it is distributed by the Xposed framework /
LSPosed projects under the Apache License 2.0.

It can be replaced with another compatible Xposed API 82 jar via `XPOSED_JAR=...`
when running `build.sh`.
